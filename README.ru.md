# Самостоятельный сервер Hysteria2

Проект собирает Hysteria 2 из закреплённого исходного commit непосредственно на
VPS. Секреты сервера, клиентские URI, QR-коды и резервные копии не попадают в
Git.

Главные отличия от одноразовой установки:

- версия не обновляется незаметно при повторном deploy;
- у каждого устройства отдельный логин и пароль;
- добавление и отзыв клиента выполняются атомарно, с проверкой во временном
  контейнере без сети и с откатом;
- контейнер read-only, без Linux capabilities и с ограничениями ресурсов;
- правило UFW удаляется только в том случае, если его создал проект;
- TCP 443 другого сервиса не конфликтует с Hysteria на UDP 443.

## Установка

```bash
git clone https://github.com/cop30/hysteria2-vpn.git
cd hysteria2-vpn
sudo INITIAL_CLIENT=iphone ./deploy.sh
```

По умолчанию используется UDP 443, Salamander, IPv4-выход и самоподписанный
сертификат с SHA-256 pin в клиентской ссылке. Сборка и весь тяжёлый трафик идут
на VPS.

## Клиенты

```bash
sudo ./add-client.sh windows
sudo ./add-client.sh iphone
sudo ./remove-client.sh old-phone
```

Профили находятся в `clients/`. Это секретные файлы. Если на сервере установлен
`qrencode`, рядом создаётся PNG. Для мобильной сети iOS разумная начальная
настройка Keepalive — 10 секунд. IPv6 следует включать только после проверки
IPv6-выхода сервера.

## Обслуживание

```bash
sudo ./status.sh
sudo ./backup.sh /защищённый/путь/hysteria2-backup.tar.gz
sudo ./deploy.sh
sudo ./rollback.sh
sudo ./cleanup.sh
```

Backup содержит все клиентские пароли и должен храниться зашифрованно вне Git.
Обновление Hysteria выполняется только явным изменением тега и SHA в
`versions.conf`, после ревью и резервного копирования.

`rollback.sh` проверяет предыдущую конфигурацию, сохраняет текущую в секретный
локальный архив и только затем переключает контейнер. После успешного возврата
заменённая версия остаётся следующей точкой rollback, поэтому действие обратимо.

Изолированная проверка уже собранного образа не открывает порт и не подключает
контейнер к сети:

```bash
sudo bash tests/smoke_image.sh local/hysteria2:v2.12.2
```
